# 벤치마킹 분석: 연포스트 (post.yeonpost.com)

> 작성일: 2026-08-10. 핵심 화면(작업 추가) 스크린샷 기반 분석.

## 서비스 정체

네이버 **카페 육성 대행업체**. 고객의 카페에 특정 소재·형태의 글을 대량으로 대신 작성해
카페 활성도와 C랭크(카페 검색 노출 순위)를 올려주는 서비스.

## 핵심 화면 구조 (작업 추가)

### 사이드바 메뉴
- 작업 추가 / 신청 현황 / 작업 현황

### 1. 카페 정보
| 항목 | 방식 |
|---|---|
| 카페 URL | 직접 입력 (`https://cafe.naver.com/...`) |
| 카페명 | URL 입력 시 자동 채움 |
| 희망 시작일 | 날짜 선택 |
| 게시판 선택 | URL 입력 시 자동 로드, 복수 선택 가능 |

> 안내문구: "확실한 C랭크 육성을 위해 **1개만** 세팅 추천. 복수 선택 시 정해진 양이 골고루 나뉘어 작업됩니다."
> → C랭크는 게시판 단위 활동성을 평가하므로 한 게시판에 집중하는 것이 육성에 유리.

### 2. 게시글 세팅
- **주제 (1개만 선택)**: 가전제품, 건강기능식품, 공구(DIY), 다이어트, 다이어트제품, 대출, 맘카페,
  맛집, 반려동물, 법률, 보험, 부동산, 성형, 여행, 연애, 요양, 웨딩, 인터넷가입, 일상, 주식,
  취업, 치과, 코인, 피부과, 핸드폰, 화장품 (26종 — 고단가 마케팅 업종 중심)
- **글 형태 (복수 선택)**: 기본 치환용 / 상세 후기형 / 추천 게시글 / 정보 공유·꿀팁형 /
  비교 분석형 / 추천 리스트형 / 질문형 게시글 (7종)
- **작업량 (30일 기준)**: 150개 / 300개 / 600개 → 일 5 / 10 / 20개

### 자연스러움 장치 (핵심 노하우)
- 글자수 **300~800자 랜덤** 발행
- 이미지는 주제와 비슷한 느낌으로 랜덤, **20% 확률**로만 삽입
- 글 형태 = "전체적인 글의 느낌" — 형태별로 다양한 톤 유지
- 가입 조건 없는 카페여야 함 (가입 후 즉시 글·댓글 작성 가능해야)

### 액션
- 원고 미리보기 / 작업 등록하기

## 핵심 화면 구조 (작업 현황)

- 상단 컨트롤: **비활성화만** 필터 / **검색** / 목록으로 / 새로고침
- **작업중 (N건)** / **작업완료 (N건)** 두 섹션으로 분리된 테이블
- 컬럼: #, 광고주, 카페명, 카페주소, 게시판, 주제, **총 포스팅 수량, 작업량**, 등록일,
  종료예정일, 상태, 관리
- 빈 상태 문구: "진행 중인 작업이 없습니다." / "완료된 작업이 없습니다."
- 시사점: 작업을 **진행중/완료 생명주기**로 관리하고, 물량(총량 vs 소화량)을 수치로 보여줌
  → 우리 버전: 총 원고 수 / 발행 수 컬럼으로 치환, 관리 컬럼에서 완료 처리

## 우리가 가져갈 것

1. **작업(Job) 단위 워크플로우**: 대상 + 주제 + 형태 + 물량을 하나의 작업으로 등록
2. **주제 × 글 형태 매트릭스**: 주제 26종, 형태 7종 그대로 채택 + 직접 입력 허용
3. **랜덤화**: 글자수 랜덤, 형태 랜덤 배분, 이미지 제안 확률적 삽입 → 기계적 패턴 방지
4. **일 단위 물량 개념**: 월 150/300/600 → 일 5/10/20개 생성

## 우리가 다르게 할 것

| 연포스트 | 우리 (magggy) |
|---|---|
| 대행업체가 자기 계정으로 남의 카페에 발행 | **내 카페/블로그에 내가 발행할 원고를 생산** |
| 카페 전용 | 카페 + **블로그(장문 SEO)** + 스레드/인스타 파생 |
| 발행까지 대행 | 원고 생성 → 복사·발행 → 발행 체크 관리 |
| 월 단위 일괄 계약 | 필요할 때 "오늘 분량 생성" 버튼 |
