# 영상 학습 노트: 블로그 대행사의 작업 방식

> 출처: 유료 강의 "볼로그스터디" (블로그 마케팅 대행사 시스템, 52분).
> 전체 요약·자막: blog-automation 저장소 `docs/블로그마케팅대행사-강의정리.md` (비공개, 개인 학습용).

## 강의에서 magggy에 반영한 것 (2026-08-10)

정상적 SEO 요소만 반영, 정책 위반 리스크 기법(사진 세탁, 블로그 구매/임대, DB 구매,
복사 방지 우회)은 **의도적으로 제외**:

- **제목 25자 이내, 키워드 1회 담백하게** (반복 금지) → 공통 가이드 초기값
- **키워드 횟수**: 1,500자 기준 메인 10~12회 + 세부 키워드 3~5회 → 공통 가이드
- **체류시간 설계**: 대표 정보를 중반 이후 배치, 사진→3~4줄 글 리듬, 인용구로 팩트 정리 → 공통 가이드
- **세부(롱테일) 키워드 공략**: 검색량 낮지만 전환 좋은 키워드를 소제목에 → 공통 가이드
- **"상위 글을 텍스트 분석해 최신 로직 역설계"** — 강사의 핵심 방법론이 우리 패턴 분석
  기능과 동일. 패턴 재분석 버튼으로 로직 변경에 대응 (강사: "로직은 정기적으로 바뀐다")
- **가이드는 데이터**: 노출 규칙을 코드가 아니라 편집 가능한 공통 가이드(/guides)로 관리

## 인사이트 두 방향

### 방향 1 — 대행사처럼 사업 확장 (장기 로드맵)

블로그 대행사의 사업 구조를 magggy 앱과 연결하면 확장 가능:

- **고객사 찾기**: 광고주(업체) 발굴 → 앱에 "고객사" 개념 추가, 고객사별 작업 분리
- **파워블로그 소싱**: 노출력 있는 블로그 확보/제휴 → 다중 블로그 계정 관리 기능
- **글 작성 가이드**: 대행사는 블로거에게 가이드를 내려줌 → 앱의 패턴 분석 결과가
  곧 "작성 가이드"가 됨. 가이드를 문서로 내보내는 기능으로 발전 가능

앱 구조상 필요해지는 것: jobs에 고객사(client) 축 추가, 블로그(계정) 관리 테이블,
가이드 내보내기(PDF/문서), 고객사별 발행 리포트.

### 방향 2 — 파워블로그 만들기 (즉시 구현 ✅)

핵심 방법론: **내 주제의 여러 키워드로 검색 → 상위 노출 블로거의 패턴을 파악 →
그 패턴을 내 블로그 글에 그대로 적용.**

magggy 구현 ("패턴 분석" 메뉴):

1. 네이버에서 키워드 검색 → 상위 노출 글 2~5개의 제목+본문 복사
2. 앱의 패턴 분석 화면에 붙여넣기 → Claude가 분석:
   - 제목 공식 (키워드 위치, 숫자/후킹 요소)
   - 글자수·문단 구조·소제목 사용 방식
   - 어투, 키워드 반복 빈도와 배치, 이미지 삽입 지점
3. 분석 결과가 "스타일 가이드"로 저장됨
4. 작업(Job)에 가이드를 연결하면 이후 생성되는 모든 원고가 그 패턴을 따름

키워드마다 노출 패턴이 다르므로, 키워드별로 가이드를 여러 개 만들어 작업마다
다른 가이드를 연결하는 운용을 권장.
