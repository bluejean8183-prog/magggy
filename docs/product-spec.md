# magggy — 마케팅 육성 콘텐츠 스튜디오

네이버 블로그/카페 육성을 위한 글을 대량 생산하는 개인용 웹 앱.
스레드/인스타그램은 만들어진 원고에서 파생하는 보조 채널.

## 사용 흐름

1. **작업 추가**: 채널(카페/블로그) 선택 → 대상 이름·URL → 주제 1개 → 글 형태 선택 → 일일 생성량
2. **원고 생성**: 작업 상세에서 "오늘 분량 생성" 클릭 → Claude API가 원고 N개 생성
   - 카페: 300~800자 랜덤, 선택한 형태 중 랜덤 배분, 이미지 제안 20% 확률
   - 블로그: 1,500~2,500자 장문, 검색 키워드 의식한 제목·소제목 구조
3. **발행 관리**: 원고 복사 → 네이버에 직접 붙여넣기 발행 → 앱에서 "발행 완료" 체크
4. **파생**: 원고에서 버튼 한 번으로 스레드(500자 훅 중심) / 인스타 캡션(해시태그 포함) 버전 생성

## 화면

- `/jobs/new` — 작업 추가 (연포스트 핵심 화면의 우리 버전)
- `/jobs` — 작업 현황 (작업 목록, 진행 상태)
- `/jobs/[id]` — 작업 상세: 원고 생성 버튼 + 원고 카드 목록 (복사/발행체크/파생/삭제)

## 기술

- Next.js (App Router) + TypeScript, better-sqlite3 로컬 DB (`data/magggy.db`)
- Claude API (`claude-opus-5`), 구조화 출력(json_schema)으로 제목/본문/태그/이미지 제안 생성
- `.env.local`에 `ANTHROPIC_API_KEY` 필요 (`.env.example` 참고)

## 데이터 모델

- `jobs`: 채널, 대상명, URL, 주제, 글 형태(JSON), 일일 생성량, 글자수 범위, 메모
- `posts`: job_id, 채널(cafe/blog/threads/instagram), parent_id(파생 원본), 제목, 본문,
  형태, 태그(JSON), 이미지 제안, 상태(draft/published/discarded)

## 나중에 (앱 발전 방향)

- 콘텐츠 캘린더 (발행 스케줄 관리)
- 키워드 리서치 보조 (연관 검색어 기반 소재 추천)
- 발행 이력 통계 (채널별 누적, 주제별 분포)
- 스레드 공식 API 자동 발행
