# 모델 후보와 가격 (OpenRouter)

> ⚠️ 이 가격은 2026-11-20에 검색 결과로 확인한 값이에요. 제 작업 환경에서는 openrouter.ai에 직접 접속이 안 돼서 **실시간으로 확인하지는 못했어요.**
> 고르기 전에 맥미니에서 아래 명령으로 **실시간 가격**을 꼭 확인해 주세요 (API 키 없이 공개 가격표만 읽어요):
>
> ```bash
> python3 ~/magggy/hermes-setup/scripts/list-models.py
> ```

조건: 유료 모델만(:free 제외), Claude 제외, 로컬 모델 제외, 도구 호출(tools) 지원.
가격은 **토큰 100만 개당 달러**예요. 한국어 대화 한 번은 보통 수천 토큰이라서, 100만 토큰이면 대화를 수백 번 할 수 있어요.

| A2 | `openai/gpt-5-nano` | 0.05 | 0.40 | 괜찮음 | 싸고 도구 호출이 안정적이에요. 긴 추론은 약해요 |
| A3 | `deepseek/deepseek-v4-flash` | 0.045 | 0.09 | 보통 | 제일 싸요. 시간대별로 가격이 바뀌는 경우가 있어요 |
| A4 | `qwen/qwen3.7-flash` | 0.03 | 0.13 | 보통 | 아주 싸요. 모델 ID를 실시간으로 확인해야 해요 |

### 대략 한 달 비용 (예시)
보고 하루 20건, 사장봇 요약 하루 5번이라고 치면 한 달에 수백만 토큰 정도예요.
→ A1과 B1 조합이면 **한 달 1~3달러 안팎**으로 예상돼요. (실제 비용은 OpenRouter 사용량 화면에서 확인할 수 있어요.)

## 저의 추천
- **직원봇: A1 `google/gemini-2.5-flash-lite`**
- **사장봇: B1 `openai/gpt-5-mini`**

둘 다 데이터를 학습에 쓰지 않는 제공자로 연결할 수 있는 모델이에요. 아래 개인정보 설정과 같이 쓰면 돼요.

## OpenRouter 개인정보 설정 (사장님이 직접 해 주세요)
1. https://openrouter.ai/settings/privacy 로 들어가세요.
2. **"학습에 쓸 수 있는 유료 제공자 허용"** (영어로는 "Enable paid endpoints that may train on inputs" 같은 문구) → **끄기**
3. **무료 모델 관련 설정**도 학습 허용이 켜져 있으면 → **끄기** (무료 모델은 쓰지 않을 거예요)
4. **프롬프트 공유로 1% 할인받기** 같은 항목이 있으면 → **끄기**
5. **Zero Data Retention(ZDR, 데이터를 저장하지 않는 제공자만 사용)** 항목이 있으면 → **켜기**
   - 켜고 나면 고른 모델이 실제로 응답하는지 꼭 테스트해 주세요. 쓸 수 있는 제공자가 줄어들 수 있어요.

헤르메스 설정 파일에도 `data_collection: deny`(데이터 수집 거부)를 넣어 두었어요. 계정 설정과 이중으로 막는 거예요.

## API 키 만들기 (사장님이 직접 해 주세요)
1. https://openrouter.ai/settings/keys 로 들어가세요. (주소가 안 열리면 오른쪽 위 프로필 메뉴에서 **Keys**를 누르세요.)
2. **Create Key**를 누르세요.
3. 키를 **두 개** 만들어요. 봇마다 따로 쓰면 한쪽이 새도 다른 쪽은 안전해요.
   - 이름 `hermes-boss`, 사용 한도(Credit limit) 예: **$5**
   - 이름 `hermes-staff`, 사용 한도 예: **$3**
4. 만들면 `sk-or-v1-...`로 시작하는 키가 **한 번만** 보여요.
   - **저에게 보내지 마세요.** 메모장에 잠깐 붙여 두었다가 2단계에서 맥미니 터미널에 직접 입력하면 돼요.
   - 다 입력하고 나면 메모장에 적어 둔 건 지워 주세요.
5. https://openrouter.ai/settings/security 에 들어가서 한도 없는 키가 있다고 나오면 한도를 걸어 주세요.

참고: 충전할 때 OpenRouter 수수료(약 5.5%)가 붙는다고 알려져 있어요.
